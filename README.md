# Volt releases

Builds of Volt, a macOS menu-bar app for your battery, AirPods and the apps using power.

- **Download:** the newest DMG under [Releases](../../releases).
- **Updates:** Volt checks `appcast.xml` once a day and installs new versions (Settings › About › Updates).
  Every update is signed; Volt only installs updates with a valid signature.

Volt is not notarized: on first launch, right-click Volt.app › Open.
